# Slither.sol 


## Overview

**Slither.sol** is an experimental project inspired by the game *Slither.io*, applied to the **Solana** ecosystem.  
The objective is to explore on-chain game logic, player interactions, and the fundamental mechanisms of a gameplay-oriented smart contract.

The project is mainly educational and serves as a base to understand:

* smart contract structuring,
* state management,
* user ↔ blockchain interactions.

---

## ⚙️ Features

* Simplified *Slither*-style game logic
* Entity management (players, positions, state)
* Modular smart contract approach
* Base usable for future extensions (scores, rewards, PvP, etc.)

---

## 🧱 Architecture

* `Slither.sol`: main contract
* State management via internal variables
* Public functions for player interactions
* Logic designed to be readable and scalable
