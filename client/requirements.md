## Packages
@solana/web3.js | Core Solana library for transactions
@solana/wallet-adapter-react | React hooks for wallet integration
@solana/wallet-adapter-react-ui | UI components for wallet connection
@solana/wallet-adapter-wallets | Standard wallet adapters (Phantom, Solflare)
@solana/wallet-adapter-base | Base types for wallet adapters
framer-motion | Smooth animations for UI transitions
react-use | Utility hooks for window size and key handling
clsx | Class name utility (often needed with tailwind-merge)
tailwind-merge | Class name merging

## Notes
- Using Solana Devnet for transactions
- Game logic is client-side simulated multiplayer (bots) for MVP performance
- Using 'Orbitron' and 'Exo 2' fonts for Cyberpunk aesthetic
- Wallet interaction requires HTTPS in production, works on localhost
